# 📊 Análise Comercial — Power BI

Projeto desenvolvido no módulo de **Ingestão de Dados** do CET de Gestão de Informação e Ciência de Dados.

### 🌐 [👉 Ver Dashboard Online](https://bias3.github.io/PROJETOS_DADOS/Power_BI/Ingestao_de_Dados/Dashboard_Comercial_BiaS3.html)

> Os dados são fictícios e foram disponibilizados no âmbito da formação.

## Sobre
Ingestão e organização de dados de múltiplas fontes (Excel, CSV, TXT, PDF) para construção de um dashboard comercial com análise de vendas 2022–2025.

## Stack
`Power BI` `Power Query` `Python` `pandas` `HTML` `Chart.js`

## Dados
| Fonte | Formato |
|-------|---------|
| Registo de Clientes | Excel |
| Registo de Lojas | Excel |
| Registo de Produtos | CSV |
| Gerentes de Loja | TXT |
| Categorias de Produtos | PDF |
