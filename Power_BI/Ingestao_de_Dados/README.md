# 📊 Análise Comercial — Power BI

## 📌 Sobre o projeto

Projeto desenvolvido durante o módulo de **Ingestão de Dados em Power BI**, no âmbito do CET de Gestão de Informação, Ciência de Dados e Business Intelligence.

O objetivo deste projeto foi praticar a ingestão e organização de dados provenientes de diferentes fontes, utilizando o Power BI para criar um dashboard de análise comercial.

> ℹ️ Os dados utilizados neste projeto são fictícios e foram disponibilizados no âmbito da formação, com autorização para utilização no portfólio.

## 📊 Dashboard

## 🗂️ Fontes de dados

Foram utilizadas diferentes fontes e formatos de dados:

* Excel — Registo de Clientes
* Excel — Registo de Lojas
* CSV — Registo de Produtos
* TXT — Gerentes de Loja
* PDF — Categorias de Produtos

## 🛠️ Ferramentas utilizadas

* Power BI Desktop
* Power Query
* Excel
* CSV
* TXT
* PDF

## 🔄 Processo

Durante o desenvolvimento do projeto foram praticadas etapas de:

* Importação de diferentes fontes de dados
* Ingestão e organização dos dados
* Tratamento dos dados
* Integração de diferentes fontes
* Criação de filtros e segmentações
* Construção de indicadores
* Criação de visualizações interativas

## 📈 Análises apresentadas

O dashboard permite analisar os dados comerciais através de diferentes perspectivas, incluindo:

* Evolução das vendas ao longo do tempo
* Vendas por género
* Vendas por país
* Vendas por marca
* Indicadores gerais de vendas
* Filtros por ano

## 📚 Aprendizados

Este projeto permitiu colocar em prática os conhecimentos adquiridos no módulo de **Ingestão de Dados**, especialmente no trabalho com diferentes fontes e formatos de dados no Power BI.
